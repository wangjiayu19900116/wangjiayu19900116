# rtl-style:RTL 代码风格规范

统一的 Verilog-2001 / SystemVerilog 编码风格。规则带编号,review 输出和代码注释中引用编号。两种用法:

- **写代码**:新写或修改 RTL 时全部规则默认生效;在已有工程中改码时,若工程现有风格与本规范冲突,**以工程现有风格为准**,保持一致性优先。
- **风格检查**:`/rtl-gen` 之外单独调用时,逐文件检查并输出违规表:`文件:行号 | 规则编号 | 问题描述 | 建议改法`,按严重度排序(会导致功能/综合问题的在前,纯风格的在后)。只报问题不改代码,除非用户明确要求顺手修。

## 1. 文件与模块组织(F)

- **F-1** 每个文件只放一个 module,文件名 = 模块名(`fifo_sync.sv` 里只有 `fifo_sync`)。
- **F-2** 文件头注释固定包含:功能一句话、参数说明、时钟/复位约定、latency、作者与日期。
- **F-3** 一律用 ANSI 风格端口声明;端口顺序:时钟 → 复位 → 按接口分组(每组内先输入后输出),组间空行加注释分隔。
- **F-4** module 内部顺序:parameter/localparam → 类型定义 → 信号声明 → 组合逻辑 → 时序逻辑 → 子模块例化 → 断言;信号声明紧邻首次使用的逻辑块之前亦可,但不许用到哪儿声明到哪儿地混杂。
- **F-5** 子模块例化一律用命名端口连接(`.clk(clk)`),禁止位置连接;未用输出显式留空 `.dbg_o()` 并注释原因。

## 2. 命名规范(N)

- **N-1** 模块名、信号名:小写 snake_case;parameter/localparam/宏:大写 SNAKE_CASE。
- **N-2** 后缀约定:低有效 `_n`;寄存器输出 `_q`(或工程惯用的 `_r`);对应的次态/组合输入 `_d`;两级同步器各级 `_ff1`/`_ff2` 或 `_sync`;格雷码 `_gray`。
- **N-3** 时钟一律 `clk` 或 `clk_<域名>`;复位一律 `rst_n` / `rst_<域名>_n`;不许出现 `clock`、`reset`、`rstn` 等变体混用。
- **N-4** 状态机:状态枚举值用 `S_` 前缀(`S_IDLE`、`S_RUN`),状态寄存器 `state_q`,次态 `state_d`。
- **N-5** 端口方向可读:建议输入 `_i`、输出 `_o` 后缀(工程没这个习惯就不加,见总则);握手对命名成对出现:`xx_valid`/`xx_ready`/`xx_data`。
- **N-6** 禁止单字母信号名(循环变量 `i`/`j` 除外)、禁止拼音命名、禁止同一含义多种缩写并存(`cnt` 和 `counter` 二选一全局统一)。

## 3. 格式(L)

- **L-1** 缩进统一(4 空格或工程现状),禁止 Tab;行宽 ≤ 100 字符。
- **L-2** 一行一条语句;`begin...end` 在多行块必加,单行 if 可省但 if-else 两分支风格一致。
- **L-3** 端口表、信号声明、例化连接做垂直对齐;位宽声明统一 `[WIDTH-1:0]` 降序。
- **L-4** 运算符两侧加空格;复杂表达式加括号明确优先级,不依赖默认优先级。
- **L-5** 每个 always 块只做一件事,块前一行注释说明用途;逻辑段落之间用空行或 banner 注释分隔。

## 4. 组合逻辑(C)

- **C-1** SV 用 `always_comb`,Verilog-2001 用 `always @(*)`;禁止手写敏感列表。
- **C-2** 块内所有被赋值信号在块首先赋默认值;`case` 必带 `default`;**任何情况下不得推断出 latch**。
- **C-3** 组合逻辑一律阻塞赋值 `=`;一个信号只在一个 always 块中赋值(单驱动)。
- **C-4** 禁止 `casex`;`casez` 仅用于优先级译码且需注释说明;优先用 `unique case` / `priority case`(SV)。
- **C-5** 禁止组合环路;组合逻辑级数过深(估计影响时序)时拆流水并在文档中记录。

## 5. 时序逻辑(S)

- **S-1** SV 用 `always_ff`,非阻塞赋值 `<=`;同一 always 块内禁止混用 `=` 和 `<=`。
- **S-2** 复位统一模板(默认异步低有效复位、同步释放,工程另有约定则从之):`always_ff @(posedge clk or negedge rst_n) if (!rst_n) ... else ...`。
- **S-3** 复位分支只复位必要的控制寄存器(状态、valid、计数器);纯数据通路寄存器可不复位,但必须保证复位后首个 valid 之前数据不被采用,并注释说明。
- **S-4** 禁止 `initial` 初始化寄存器(FPGA 工程明确允许时例外并注释)、禁止 `#delay`、`force/release`、层次引用等不可综合语句。
- **S-5** 寄存器自增/计数必须明确位宽与回绕行为:`cnt_q <= cnt_q + 1'b1;` 回绕是否有意,注释写清。

## 6. 状态机(M)

- **M-1** 三段式:状态寄存(时序)/ 次态译码(组合)/ 输出逻辑(组合或寄存输出,选型写进设计文档)。
- **M-2** 状态用 `typedef enum logic [N-1:0]`(SV)或 `localparam`(Verilog)定义,禁止裸数字比较状态。
- **M-3** 次态 `case` 的 `default` 回到安全状态(通常 `S_IDLE`),非法状态不得静默停留。
- **M-4** 输出尽量由状态唯一决定(Moore 优先);必须用 Mealy 时注释标明输入到输出的组合路径。

## 7. 位宽与运算(W)

- **W-1** 所有常量带宽度和进制(`4'd10`、`8'hFF`);禁止裸 `0`/`1` 参与拼接或位运算(循环边界等纯软件语境除外)。
- **W-2** 赋值两侧位宽一致;确需截断/扩展时显式写出切片或拼接,并注释截断是否安全。
- **W-3** 有符号运算统一用 `signed` 类型全程保持,禁止 signed/unsigned 混用让工具隐式转换。
- **W-4** 派生宽度一律 `$clog2()` + parameter,禁止手算常数写死。

## 8. 跨时钟域(D)

- **D-1** 单 bit 电平信号过域:两级(高频域可三级)同步器,专用模块或统一命名 `_ff1/_ff2`,同步器输入端禁止组合逻辑(先打一拍再过域)。
- **D-2** 多 bit 过域:格雷码指针、握手或异步 FIFO 三选一,禁止多 bit 直接双触发器同步。
- **D-3** 脉冲过域用脉冲同步器(toggle + 边沿检测),并保证源脉冲间隔满足约束,注释写明。
- **D-4** 每个 CDC 边界代码处必须有 `// CDC:` 注释,标明源域/目的域和所用结构;同步器寄存器建议加 `(* ASYNC_REG = "TRUE" *)` 属性(FPGA)。

## 9. 注释(X)

- **X-1** 注释写"为什么"和约束,不复述代码字面意思;魔法数字、非常规写法、豁免的 lint 警告必须就地注释原因。
- **X-2** 文件头(F-2)、always 块用途(L-5)、CDC 边界(D-4)、假设与限制为四类强制注释。
- **X-3** 注释与代码同步修改;禁止遗留大段注释掉的死代码(要留必须注明原因和日期)。

## 10. 快速自查清单

交付前按序扫一遍:无 latch(C-2)→ 单驱动(C-3)→ 无 `=`/`<=` 混用(S-1)→ case 全带 default(C-2/M-3)→ 常量带位宽(W-1)→ 复位行为明确(S-2/S-3)→ CDC 全部有注释(D-4)→ 无不可综合语句(S-4)→ 命名后缀一致(N-2/N-3)。有条件时再跑机器 lint(verilator --lint-only -Wall),工具警告优先于本清单。
